## 4. 1-Click Instant Cleanup Commands (PowerShell)

Whenever you want to quickly purge all scratch, cache, or temporary files without searching:

### Quick Clean (Purge transient build & test caches only):
```powershell
# Cleans Next.js cache, test reports, and temporary logs
Remove-Item -Recurse -Force -ErrorAction SilentlyContinue frontend/.next, frontend/playwright-report, frontend/test-results, eval/report.md, .vercel
Write-Output "✅ Build & test caches purged successfully."
```

### Deep Clean (Purge all Python bytecode, caches, and test artifacts):
```powershell
Get-ChildItem -Path . -Include __pycache__, .pytest_cache, .mypy_cache, .ruff_cache -Recurse -Force | Remove-Item -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force -ErrorAction SilentlyContinue frontend/.next, frontend/playwright-report, frontend/test-results, eval/report.md, .vercel
Write-Output "✅ Deep cleanup completed. Zero leftover scratch artifacts."
```
