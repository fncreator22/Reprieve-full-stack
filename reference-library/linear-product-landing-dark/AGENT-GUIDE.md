## 📌 Best Suited For
1. **Developer Tooling & Technical SaaS Landings:** Perfect foundation for platforms with engineering, devops, security, or product management audiences.
2. **Keyboard-Driven User Experiences:** Applications integrating command bars (`Cmd+K`), tactile keyboard shortcut hints, and quick-filter lists.
3. **Atmospheric Dark Interfaces:** High-end dark designs requiring subtle radial glows, illuminated borders, and gradient highlights without neon oversaturation.
4. **Interactive Feature Showcases:** Micro-application simulations (interactive kanban cards, cycle burndowns, status badges) that engage users directly on the marketing page.

## ⚠️ Avoid When
1. **Bright, Content-Dense Document Readers:** Reading blogs, legal document repositories, or e-commerce storefronts where black canvases increase eye fatigue.
2. **Ultra-Budget Low-Power Deployments:** High-frequency cursor tracking and multi-layer backdrop blurs can throttle CPU on budget low-tier mobile devices without proper media queries (`@media (hover: hover)`).
3. **Strict Accessible High-Contrast Light Applications:** Organizations that mandate WCAG AAA high contrast with strict light backgrounds should pair this with an equally rigorous light theme.
