# Visual Asset & Screenshot Manifest: linear.app

## 1. Asset Strategy & Rendering Architecture
`linear.app` avoids heavy raster graphics and bitmap hero images in favor of **hardware-accelerated DOM rendering, native SVG vectors, and mathematical CSS gradient shaders**. This ensures instant sub-second page loads, razor-sharp vector clarity on Retina and 4K displays, and real-time interaction readiness.
