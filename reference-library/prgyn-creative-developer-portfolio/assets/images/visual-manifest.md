# Visual Asset & Screenshot Manifest: prgyn.dev

## 1. Asset Storage & Visual Strategy
In `prgyn.dev`, there are **no static PNG or JPEG marketing mockups** used to render the interface. The entire website is rendered via high-precision DOM elements, vector SVG paths, and HTML5 `<canvas>` contexts.
